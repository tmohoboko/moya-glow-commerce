# QA Cycle 01 — Moya Glow Commerce

## Environment
Production: https://moya-glow-commerce.vercel.app

## Requirements
REQ-001 — Product catalogue
Users can view the product catalogue.

REQ-002 — Product search
Users can search for products.

REQ-003 — Category filtering
Users can filter products by category.

REQ-004 — Add to cart
Users can add products to the cart.

REQ-005 — Quantity management
Users can increase or decrease cart quantities.

REQ-006 — Remove from cart
Users can remove products from the cart.

REQ-007 — Subtotal calculation
The cart subtotal reflects prices and quantities correctly.

REQ-008 — Empty cart
The application displays an appropriate empty-cart state.

REQ-009 — Responsive behaviour
The storefront remains usable on desktop and mobile.

REQ-010 — Invalid navigation
Invalid routes do not cause a fatal application failure.
